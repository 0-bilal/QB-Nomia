# QB-Nomia

محفظتك المالية الشخصية — تطبيق PWA بهوية سوداء لإدارة حساباتك، مصاريفك، اشتراكاتك، وسلفك المالية.

راجع [`QB-NOMIA-BLUEPRINT.md`](./QB-NOMIA-BLUEPRINT.md) للفكرة الكاملة والهوية البصرية وخارطة الطريق.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## مزامنة Google Sheets

راجع [`google-apps-script/README.md`](./google-apps-script/README.md) لخطوات نشر سكربت `google-apps-script/Code.gs` وربطه. الرابط والرمز السري يُضبطان **بالكود مباشرة** بملف `src/config/sheetsSync.ts` (وليس من داخل واجهة التطبيق)، ثم يُنشر إصدار جديد. البيانات تُشفَّر بالكامل محليًا (AES-GCM) قبل الإرسال وبعد الاستقبال — جدول Sheets لا يخزّن سوى نص مشفّر غير مقروء.

## الحالة الحالية

- ✅ تسجيل الدخول بالرقم السري (PIN، 4 أرقام ثابتة) — إنشاء، تحقق، قفل تلقائي عند مغادرة التطبيق.
- ✅ الحسابات (كاش/بنكي/ادخار/محفظة رقمية) — إضافة حساب، تحويل بين الحسابات، عرض آخر حركات كل حساب.
- ✅ المصاريف والدخل والتحويلات (إدخال المبلغ بلوحة أرقام مخصصة بهوية التطبيق، بدون كيبورد الهاتف)، فئات المصاريف بميزانية شهرية، مصادر الدخل.
- ✅ الاشتراكات — بما فيها محافظ رقمية (Google Play) يمكن شحنها وتسديد الاشتراكات منها.
- ✅ السلف المالية — إدارة الأشخاص، دفتر حساب جارٍ لكل شخص، تواريخ استحقاق.
- ✅ مزامنة Google Sheets مشفّرة من الطرفين (رفع/سحب يدوي، + سحب تلقائي صامت بعد تسجيل الدخول).
- ✅ مسح ذاكرة التخزين المؤقت (المزيد) — بدون بيانات تجريبية بالتطبيق أصلًا.
- 🔜 التقارير، الإشعارات، مزامنة تلقائية بالخلفية.

التطبيق يبدأ فارغًا تمامًا (بدون حسابات أو حركات وهمية) — أنت تبني بياناتك من الصفر. البيانات مخزّنة محليًا (localStorage) دائمًا، مع إمكانية مزامنتها بجدول Google Sheets خاص بك.
