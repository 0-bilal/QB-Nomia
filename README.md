# QB-Nomia

محفظتك المالية الشخصية — تطبيق PWA بهوية سوداء لإدارة حساباتك، مصاريفك، اشتراكاتك، وسلفك المالية.

راجع [`QB-NOMIA-BLUEPRINT.md`](./QB-NOMIA-BLUEPRINT.md) للفكرة الكاملة والهوية البصرية وخارطة الطريق.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## مزامنة Google Sheets

راجع [`google-apps-script/README.md`](./google-apps-script/README.md) لخطوات ربط التطبيق بجدول Google Sheets خاص بك (نشر سكربت `google-apps-script/Code.gs`، ثم ربط الرابط من داخل التطبيق عبر **المزيد ← ربط Google Sheets**).

## الحالة الحالية

- ✅ تسجيل الدخول بالرقم السري (PIN، 4 أو 6 أرقام) — إنشاء، تحقق، قفل تلقائي عند مغادرة التطبيق.
- ✅ الحسابات (كاش/بنكي/ادخار/محفظة رقمية) — إضافة حساب، تحويل بين الحسابات، عرض آخر حركات كل حساب.
- ✅ المصاريف والدخل والتحويلات، فئات المصاريف بميزانية شهرية، مصادر الدخل.
- ✅ الاشتراكات — بما فيها محافظ رقمية (Google Play) يمكن شحنها وتسديد الاشتراكات منها.
- ✅ السلف المالية — إدارة الأشخاص، دفتر حساب جارٍ لكل شخص، تواريخ استحقاق.
- ✅ مزامنة Google Sheets يدوية (رفع/سحب) عبر Google Apps Script.
- ✅ إدارة البيانات (المزيد): مسح الذاكرة المؤقتة، حذف البيانات التجريبية وتصفير الحسابات.
- 🔜 التقارير، الإشعارات، مزامنة تلقائية بالخلفية.

البيانات مخزّنة محليًا (localStorage) دائمًا، مع إمكانية مزامنتها يدويًا بجدول Google Sheets خاص بك.
