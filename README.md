# QB-Nomia

محفظتك المالية الشخصية — تطبيق PWA بهوية سوداء لإدارة حساباتك، مصاريفك، اشتراكاتك، وسلفك المالية.

راجع [`QB-NOMIA-BLUEPRINT.md`](./QB-NOMIA-BLUEPRINT.md) للفكرة الكاملة والهوية البصرية وخارطة الطريق.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الحالة الحالية

- ✅ تسجيل الدخول بالرقم السري (PIN) — إنشاء، تحقق، قفل تلقائي عند مغادرة التطبيق.
- ✅ الحسابات (كاش/بنكي/ادخار) — عرض الأرصدة وهدف الادخار.
- ✅ السلف المالية — إدارة الأشخاص، دفتر حساب جارٍ لكل شخص، إضافة حركات (أعطيته/استلمت منه)، تواريخ استحقاق.
- 🔜 المصاريف والفئات، مصادر الدخل، الاشتراكات، التقارير، مزامنة Google Sheets.

البيانات مخزّنة محليًا (localStorage) حاليًا كمرحلة أولى، وستُستبدل بمزامنة Google Sheets في مرحلة لاحقة حسب خارطة الطريق.
