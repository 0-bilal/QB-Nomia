# مزامنة QB-Nomia مع Google Sheets (مشفّرة بالكامل)

هذا المجلد فيه كود Google Apps Script (`Code.gs`) اللي يحوّل جدول Google Sheets عندك لمخزن مزامنة للتطبيق. البيانات تُشفَّر بجهازك بالكامل **قبل** ما تُرسل، وتُفكّ **بعد** ما تُستقبل — جدول Sheets نفسه لا يخزّن ولا يشوف أي رقم أو اسم مالي حقيقي، فقط نص مشفّر عشوائي.

## خطوة بخطوة

### 1) أنشئ جدول بيانات جديد
اذهب إلى [sheets.new](https://sheets.new) وسمّه مثلًا "QB-Nomia Data".

### 2) افتح محرر Apps Script
من القائمة العلوية: **Extensions ← Apps Script**.

### 3) الصق الكود
احذف كل محتوى `Code.gs` الافتراضي، وانسخ **كل** محتوى ملف [`Code.gs`](./Code.gs) هنا والصقه مكانه.

### 4) غيّر الرمز السري
بأعلى الملف:
```js
var SECRET_TOKEN = 'CHANGE-ME-TO-A-LONG-RANDOM-SECRET'
```
غيّره لنص عشوائي طويل من اختيارك (20+ حرف/رقم). هذا الرمز يُستخدم مرتين:
- بهذا السكربت: يتحقق منه قبل قبول أي طلب قراءة/كتابة.
- بإعدادات التطبيق (المزامنة ← الرمز السري، خطوة 7 تحت): يُشتق منه مفتاح التشفير محليًا.
**لازم تكون نفس القيمة بالضبط بالمكانين.**

### 5) شغّل `setup` مرة واحدة
اختر الدالة **setup** من القائمة بمحرر Apps Script واضغط **Run**. أول مرة بيطلب صلاحيات (Authorize access) — وافق (يشتغل بحسابك أنت على جدولك أنت فقط). بينشئ ورقة وحيدة اسمها `sync_data` لتخزين النص المشفّر.

### 6) انشر كـ Web App
**Deploy ← New deployment** ← نوع **Web app**:
- **Execute as**: Me
- **Who has access**: Anyone

اضغط **Deploy** وانسخ الرابط المنتهي بـ `/exec`.

### 7) اربطه بالتطبيق
من التطبيق: **المزيد ← مزامنة Google Sheets** — الصق رابط الـ Web App والرمز السري بحقول الإعداد واضغط **حفظ إعدادات الربط**.

⚠️ **مهم بما إن المستودع عام (public) على GitHub:** الرابط والرمز **لا يُكتبان بالكود إطلاقًا** — يُحفظان فقط بمتصفح جهازك (`localStorage`)، فما يظهران بالكود المصدري ولا بتاريخ الـ commits ولا لأي زائر ثاني للموقع. يعني لازم تدخلهما مرة وحدة بكل جهاز تستخدم منه التطبيق (جوالك، جهاز ثاني...).

بعدها زرّي **رفع البيانات** و**سحب البيانات** يشتغلون، وأي تعديل جديد (حركة، حساب، سلفة...) يُرفع تلقائيًا بالخلفية بدون الحاجة تدخل "المزيد" كل مرة.

## تحديث الكود لاحقًا

أي تعديل على `Code.gs` بمحرر Apps Script **ما يشتغل تلقائيًا** — لازم:
**Deploy ← Manage deployments ← ✎ (تعديل) ← Version: New version ← Deploy**.

## كيف تشتغل المزامنة

- **التشفير**: كل بيانات التطبيق (كل الحسابات، الحركات، الأشخاص...) تُجمع بجهازك، تُشفَّر بالكامل بخوارزمية AES-GCM بمفتاح مشتق من `SHEETS_SECRET_TOKEN` (عبر `src/lib/cryptoUtil.ts`، بنفس أسلوب Web Crypto API المستخدم لتشفير الرقم السري)، ثم تُرسل كنص واحد مشفّر. السكربت يخزّنه كما هو بخلية واحدة بورقة `sync_data` — بدون أي معالجة أو فك تشفير من طرفه.
- **رفع تلقائي بالخلفية**: أي إضافة/تعديل بالتطبيق (حركة، حساب، سلفة، اشتراك...) يجدول رفعًا تلقائيًا خلال ثانية أو ثانيتين، بدون ما تفتح "المزامنة" أو تضغط أي زر — شريط صغير أعلى الشاشة يوضح "جارٍ الحفظ الاحتياطي" وقت الرفع.
- **رفع يدوي (Push)**: يستبدل النص المشفّر المخزّن بالكامل بالنسخة الجديدة فورًا — مفيد للتأكد أو لو الجهاز كان بدون إنترنت وقت آخر تعديل.
- **سحب (Pull)**: يجيب النص المشفّر، يفكّ تشفيره محليًا بجهازك، ويستبدل به كل البيانات المحلية الحالية بالكامل — عملية يدوية بزر واضح مع تأكيد، تُستخدم لاسترجاع بياناتك بجهاز جديد.
- ما فيه دمج ذكي للتعارضات — آخر جهة رفعت (تلقائيًا أو يدويًا) أو سحبت هي اللي تفوز.
- **بدون إنترنت**: التطبيق يعمل بالكامل بدون اتصال (بياناتك محلية دائمًا)؛ الرفع التلقائي فقط يتأجل حتى يرجع الاتصال، ويظهر شريط "غير متصل" أعلى الشاشة بدل محاولة فاشلة.

## الأمان

- **تشفير من الطرفين**: البيانات مشفّرة قبل الإرسال وبعد الاستقبال دائمًا — حتى لو انكشف رابط الـ Web App، اللي يشوفه بس نص عشوائي غير مفهوم بدون الرمز السري.
- **الرمز السري لا يوجد بالكود إطلاقًا** — يُدخَل من "المزيد ← مزامنة Google Sheets" ويُحفظ فقط بمتصفح كل جهاز (`localStorage`)، ما يظهر بالمستودع (وهو عام على GitHub) ولا بتاريخ الـ commits ولا لأي زائر ثاني.
- السكربت يشتغل بحسابك أنت فقط (Execute as: Me) — ما يعطي وصول لأي شيء غير هذا الجدول المحدد.
- كل جهاز جديد يحتاج تدخل الرابط والرمز مرة وحدة بنفسه.
