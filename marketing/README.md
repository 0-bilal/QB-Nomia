# ريل QB-Nomia التسويقي

فيديو عمودي 9:16 (1080×1920، 34 ثانية) لتيك توك وريلز إنستغرام ويوتيوب شورتس، بنفس هوية التطبيق (Nomia Mono).

| الملف | الوصف |
|---|---|
| `reel.html` | الأنيميشن نفسه. افتحه في المتصفح ويشتغل بلا توقف. مسافة = إيقاف، الأسهم = تقديم وترجيع، الضغط = من البداية |
| `render-reel.mjs` | يصدّره فيديو MP4 إطارًا إطارًا |
| `qb-nomia-reel.mp4` | الفيديو الجاهز |

## المشاهد

1. السؤال: «الراتب نزل... وبعد أسبوعين، وين راح؟» مع مصاريف صغيرة تطفو
2. التسرّب: رصيد ينزل من 8,500 إلى 312
3. الشعار: QB-Nomia، محفظتك المالية الشخصية
4. الرئيسية: الرصيد ومنحنى الرصيد والحسابات
5. إضافة مصروف: زر + ثم الكبسولة ثم اللوحة ثم «انحفظ» في الجزيرة
6. تدفّق الشهر: دخل مقابل صرف، وحلقات الفئات
7. السلف والاشتراكات وبرمجيات QB
8. الخصوصية: بصمة، بدون نت، Google Sheets
9. الختام: «ثبّت التطبيق» والرابط

## إعادة التصدير

```bash
node marketing/render-reel.mjs 30
```

يحتاج Playwright (Chromium) و ffmpeg. الفيديو بدون صوت عمدًا: أضف صوتًا رائجًا من مكتبة المنصة نفسها وقت النشر.
